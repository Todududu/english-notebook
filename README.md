# English Notebook

Trang học tiếng Anh cho thiếu nhi, trình độ Cambridge Movers và Flyers: flashcard, từ vựng, bài tập, kiểm tra, luyện nghe và chế độ "tắm ngôn ngữ".

| File | Nội dung |
|---|---|
| `index.html` | Trang chọn trình độ |
| `movers-english-notebook.html` | Trang học Movers (18 unit) |
| `flyers-english-notebook.html` | Trang học Flyers (18 unit) |
| `movers-english-data.txt`, `flyers-english-data.txt` | Dữ liệu học dạng txt, có thể sửa rồi nhập lại qua mục "Dữ liệu học" trên trang |

Tiến độ học được lưu trong trình duyệt của từng máy.
