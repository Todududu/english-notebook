01Kết nối GitHub chưa kết nối

Cách tạo mã truy cập (làm một lần)
  1. Mở github.com/settings/personal-access-tokens/new (đăng nhập GitHub nếu được hỏi).
  2. Token name: đặt tên dễ nhớ, ví dụ english-notebook. Expiration: chọn thời hạn (ví dụ 1 năm).
  3. Repository access: chọn Only select repositories → chọn repo english-notebook.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) và dán vào ô ở trên.

Mã chỉ được lưu trong trình duyệt của máy này và chỉ gửi tới GitHub. Đừng chia sẻ mã cho người khác. Trên máy dùng chung, bỏ tick “Ghi nhớ trên máy này”. Nếu lỡ lộ mã, vào trang token trên GitHub và bấm Revoke.
